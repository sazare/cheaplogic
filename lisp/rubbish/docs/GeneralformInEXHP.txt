一般形について

literal L 
Lからatomic Aを作る(signeを無視する)

Aの引数をすべて異なる変数にしたものをAの一般形と呼ぶ。
このとき導入される変数を一般化変数と呼ぶ。

一般形の変数は述語記号について一意とする。

Aの１番形をA^0, Lの一般形をL^0と右肩に0をつけてあらわす。

clause C = L1vL2v...vLk
とするとき
C^0 = ∨i Li^0
とする

Cの変数は、Liの引数にでてこないものもある。
つまり +P(f(x))-Q(g(x,y), y)
のような場合、xは一般形では対応する変数を持たない。
このような変数は、clauseの外側からは隠された変数という意味で「内部変数」と呼ぶことにする。
適切な名前かどうかはまだわからない。
媒介変数とか固有変数とか。

Li^0の変数はすべて異なるので、Cの変数はリテラルごとにグループ化して持てる。
ただし、内部変数がclauseのliteralの間の関係を維持している。
その点では媒介変数もいい。

例1 
 ① +P(x,x) -R(x)
 ② -P(a,y) +Q(y)

  Pの一般化変数をVとUとすると
　+P(U,V)と-P(U,V)が一般化リテラルになる。

clsuseの集合Σについて

　Σ^0 = {C1^0, C2^0, ..., Cm^0}

と定義する。Σ^0の要素数は一般形として同型のclauseがある場合、Σの要素数より少なくなる。

Σが与えられた時
Σ^0がつくれて、
全述語P in ΣについてAtomic な P^0が一意に定義できる。

clause set Cについて
　#C = (σi | σi = <Li : Li^0> )
が考えられる。

Cの全Literal L についてそれの一般化Literal L^0 のatomicなunificationによる
　σi = <Li : Li^0>
を並べたものである。
Cの変数はLiの変数つまり引数の並びを並べたものと、内部変数になる。

　内部変数が出現するLiteralの変数は内部変数を含むが、そうでないものは引数の項のリストになる。

こうして、literalごとにmguを求めると、一般形Litralについてはmgu σiの代入される方の変数がすべてことなる。
内部変数がliteral間の関係を表している。


-----------------
σとσ1, σ2の関係
　σ = <A1:A2>で
　σ1  = <A1:A1^0>
　σ2  = <A2:A2^0>
として、
　つまりA1とA2は同じ述語記号なので、一般形は同じだから
　その引数を(U, V)とすると

　簡単な場合は、σ1とσ2 を合成するとき、同じ左変数(一般化変数)を持つ項は
　　σ1 = (U, V) ← (t1, s1)
　　σ2 = (U, V) ← (t2, s2)
　　から
　　σ = σ1 ⚪︎ σ2 = (U,V) ← (<t1:t2>, <s1:s2>)

　と定義できれば、<t1:t2>と<s1:s2<は <A1:A2>のmguと同じはずなので同等になるような気もする。

　ただ、A1やA2に固有変数があると、どうなるのか??
